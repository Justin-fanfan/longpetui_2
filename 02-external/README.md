# 外部系统边界

[← 根目录](../README.md)

LongPet 宠物端存在两个外部节点：

1. [龙芯高性能 AI 推理服务器](AIServerBoundary.md)
2. [家属 Electron 应用](FamilyAppBoundary.md)

本目录只定义**宠物侧如何看待它们、交换什么数据以及失联如何降级**，不强制规定外部节点内部必须使用什么语言或框架。

## 总原则

```text
外部 AI：增强能力，不是本地自治的替代品
家属端：查看/配置业务，不是远程数据库管理员
```

两条链路的故障都不应导致宠物 UI、Reminder、基本 KWS、基础视觉和本地创意功能整体停止。
